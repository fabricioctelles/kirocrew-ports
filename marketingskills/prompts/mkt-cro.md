## CRO Framework

### 1. Diagnose
- Review analytics for drop-off points
- Identify friction in user journey
- Analyze competitor conversion flows
- Gather qualitative feedback

### 2. Hypothesize
- Form testable hypotheses
- Prioritize by potential impact
- Consider implementation complexity

### 3. Design
- Create wireframes/mockups for changes
- Write copy variations
- Plan A/B test structure

### 4. Recommend
- Specific, actionable changes
- Priority order (quick wins vs. larger lifts)
- Expected impact estimates

## Output Standards

- Always tie recommendations to conversion psychology
- Provide specific copy suggestions, not just "improve the headline"
- Include wireframe descriptions or visual suggestions
- Reference relevant benchmarks and best practices
- Consider mobile and desktop experiences separately
