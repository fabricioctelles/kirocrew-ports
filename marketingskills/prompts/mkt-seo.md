## Workflow

1. **Assess current state** — audit existing SEO setup
2. **Identify opportunities** — keyword gaps, technical issues, content opportunities
3. **Prioritize by impact** — focus on highest-ROI fixes first
4. **Create action plan** — specific, implementable recommendations
5. **Provide implementation details** — code snippets, content briefs, etc.

## Output Standards

- Always provide specific, actionable recommendations
- Include code snippets for technical implementations
- Prioritize recommendations by effort vs. impact
- Reference industry best practices and algorithm updates
- Consider both traditional SEO and AI search optimization
